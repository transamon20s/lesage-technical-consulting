LESAGE TECHNICAL CONSULTING — WEBSITE STARTER

Files:
- index.html: responsive one-page website
- beach-launch.jpg: supplied background photo (copied from the uploaded image)

BEFORE PUBLISHING:
1. In index.html, replace YOUR-EMAIL@example.com with your real business email address.
2. Review all service descriptions to ensure they match what you intend to offer.
3. The contact link uses the visitor's email app; it is not a backend contact form.
4. Add your final phone number, business location/service radius, privacy policy, and any required legal details if desired.
5. Test on mobile and desktop before publishing.

PREVIEW:
Open index.html in a web browser. Keep beach-launch.jpg in the same folder.

PUBLISHING:
This static site can be hosted on a basic web host, GitHub Pages, Cloudflare Pages, or an object-storage/static hosting service. Upload both index.html and beach-launch.jpg together.
